# LinkedIn 技能人群截面：采集与判读规则（采集前写定）

日期：2026-10-02　｜　状态：**10/4 停用，未正式采集**　｜　采集人：邱正陽（手动，本人账号）

> **停用说明（2026-10-04）**：试查时香港「全部会员」显示 4,800,000+，高于香港劳动人口约 380 万。估算是账户数、四舍五入、只给下限，当人数用不可信。另外界面只能单选一种资料语言，地点要选「永久」。8 次查询一次也没有正式记录。改用 OECD.AI 发布的 LinkedIn 官方汇总数据，见 `docs/LinkedIn数据_OECD.AI_2026-10-04.md`。下面的规则保留原样，作为记录。

## 用途

一次性的 2026 年截面，作为第七章 7.4「人才持平只对学术作者成立」的事后佐证。**不进入 RQ1 轨迹与 RQ2 先行检验**（没有历史数据）。

## 采集（手动，不用任何自动化工具；LinkedIn 用户协议禁止插件与脚本访问）

- 入口：LinkedIn Campaign Manager → 新建广告活动（目标「品牌认知」）→ 受众设置。**不绑卡、不发布。**
- 地点类型：两城使用同一选项，并记录选的是哪一个。
- 8 次查询（技能为「任一命中」）：

| 编号 | 地点 | 技能条件 |
|---|---|---|
| LI-HK-ALL / LI-SG-ALL | Hong Kong SAR / Singapore | 无 |
| LI-HK-AI / LI-SG-AI | 同上 | Machine Learning；Deep Learning；Computer Vision；Natural Language Processing |
| LI-HK-BIO / LI-SG-BIO | 同上 | Biotechnology；Clinical Research；Drug Discovery；Genomics |
| LI-HK-FIN / LI-SG-FIN | 同上 | Financial Technology；Blockchain；Payments；Digital Banking |

- 每次记录界面显示的「目标受众规模」原样（区间或约数照抄），截图命名 `LI-HK-AI_2026-10-0X.png`。
- 某项技能在界面上不存在时，记录实际可选的替代项并截图，不临时增删其他技能。

## 计算

- 人数比 = 香港人数 ÷ 新加坡人数（各产业）。
- 渗透率比 =（香港技能人数 ÷ 香港全体会员）÷（新加坡技能人数 ÷ 新加坡全体会员），用来抵消两城 LinkedIn 使用率的差别。
- 显示为区间时取区间中点，并报告用区间两端算出的范围。

## 判读（与学术作者的研究者存量港/星比值对照：AI 1.05、生医 1.13、金融科技 1.47，2024Q4）

| 结果 | 写法 |
|---|---|
| 人数比 ≤ 学术比值 × 0.8 | 「以业界技能人群计，香港相对新加坡少于学术作者口径」，支持 7.4 |
| 人数比 ≥ 学术比值 × 1.2 | 「业界技能人群的港星比并不低于学术口径」，不支持 7.4，正文照实修改 |
| 其间 | 「两种口径大致一致，无法区分」 |

渗透率比只作补充说明，不改变判读。三个产业分别判读，不合成。

## 必须同时交代的局限

会员账户 ≠ 在职人数（含不活跃账户）；数字经四舍五入，少于 300 不显示；技能为会员自填；只有 2026 年截面；两城平台使用率不同。
