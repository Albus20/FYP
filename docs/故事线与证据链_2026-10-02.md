## 一句话

**香港的人才与研究活动已与新加坡持平甚至领先，落差集中在「研究 → 知识产权」这一段：大学专利与企业专利都只有新加坡的二到五成；
到了企业端，研究端的领先也消失了。这个落差三个产业都有，是城市层面的，而且人才越追越近、专利比值却没有跟上。**

图 3 是这张表的图形版。

**读法**：

1. 研究端三项在三个产业都在 1.0 以上；生医的临床试验更是 1.74 倍。
2. 一进入知识产权段就骤降：大学专利 0.32–0.47，企业专利 0.16–0.37。
3. **大学专利这一项是关键**：它不受「跨国公司把亚太知识产权实体设在新加坡」的影响，仍然只有新加坡的三到五成，
   说明落差不只是登记地造成的。
4. 企业端：生医企业申办的临床试验与新加坡持平（0.97），全部试验的 1.74 倍领先来自大学与医院发起的试验。
5. 金融科技的快速支付（1.40）是金管局建的公共基础设施的使用量，不在转化链上，作为对照：公共推动的部分跑得快。

**补充（不进图）**：公共研究机构专利，人工智能港星相当（0.94），生物医药香港只有新加坡的 0.18——
新加坡科技研究局（A*STAR）等公共研究机构在生医上申请专利很多，两城公共科研体制不同，单独说明。

## 二、剪刀差：人才在追上，专利没有跟上（图 4）

| | 研究者存量 2017 → 2024 | 大学专利 2015–17 → 2021–23 | 企业专利 2015–17 → 2021–23 |
|---|---|---|---|
| 人工智能 | 0.68 → **1.05** | 0.33 → 0.32 | 0.26 → **0.16** |
| 生物医药 | 0.85 → **1.13** | 0.52 → 0.47 | 0.64 → **0.37** |
| 金融科技 | 0.77 → **1.47** | （量太小） | 0.18 → 0.22 |

人工智能与生物医药：人才比值上升、企业专利比值下降，形成剪刀差；大学专利比值大致不变。
金融科技：人才比值大幅上升，企业专利比值低位徘徊（中间一度升到 0.37，2023 年回落到 0.22）。
人工智能的大学专利件数少（香港每年 2–17 件），比值跳动大，只读趋势不读单年。

## 四、留给红队的问题（这条故事线最可能被攻击的地方）

1. **登记地**：香港企业把研发和知识产权放在内地或新加坡，香港的专利数会被低估。大学专利能部分排除这一点，但能排除多少？
2. **专利倾向**：两城大学的专利申请政策、技术转移办公室力度不同，大学专利低是「转化弱」还是「不爱申请」？
3. **人均与规模**：香港人口约为新加坡的 1.27 倍，人均后所有比值再小约两成；研发总投入两城差多少？
4. **OpenAlex 版本漂移**：研究端比值来自 9/11 版本，10/2 版本中香港生医论文少 18%，研究端「持平」是否稳？
5. **产业边界**：同一产业内部的细分构成不同（例如香港 AI 偏应用），会不会把细分差异读成转化差异？
6. **因果方向**：RQ2 检验力只够侦测 |r| ≥ 0.51（m1 为 0.65），「没有带动」能说到什么程度？
7. **外部印证**：官方统计（研发开支占 GDP、企业研发占比）与香港政府自己的政策判断（「中游、下游」薄弱）是否一致？
