## 拿脚本与交付

- **拿脚本**：组长直接发文件给你（或从 https://github.com/Qiuu2/FYP 的 `scripts/` 单独下载那一个文件），放进你原来的 `data_repo\scripts\` 覆盖同名文件。不需要 git。
- **在哪跑都行**：上面的命令是在 `data_repo` 文件夹里跑的写法；在 `scripts` 文件夹里就去掉 `scripts\`；用 PyCharm 就在运行配置里 Parameters 填 `--full`、Environment variables 填 `COLLECTOR_NAME=賈贇`。如果你的 `data_repo\.keys.env` 里写了 COLLECTOR_NAME 和 OpenAlex key，新脚本会自己读，不用再设。
- **交付**：完成一项就开一个 GitHub pull request（10/2 这样交的很好：只加文件、不改别人的文件），或者打包发给组长。文件名不用改。
- **请求日志（.requests.tsv）放 `manifests/`，不要放 `raw/`**：`raw/` 里每个文件都必须有 manifest，多出一个日志文件会让 `manifest.py verify` 报错。J4-2 的请求日志 9/30 已经收到并放进 `manifests/` 了，不用再发。
